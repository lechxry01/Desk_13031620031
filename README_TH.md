# AI Trading Desk PRO – Phase 5+ (Trading Floor: 6 บอทคุยกันในแชทเดียว)

Phase 5 เพิ่มห้องแชท Chief/Scout/News/Sentiment/Charts/Skeptic, แดชบอร์ด Survival (balance, P/L, win rate, uptime) และการ์ด BIG FILL — Skeptic ค้านได้และบล็อกการเข้าเมื่อค้าน ≥ 3 ข้อ · Sentiment เป็น proxy จากวอลุ่ม/ราคา ไม่ได้อ่านโซเชียล · ประวัติแชทอยู่ในหน่วยความจำ หายเมื่อเซิร์ฟเวอร์รีสตาร์ท

## โหมดทีม (เลือกได้ในหน้า Auto Trading)

| โหมด | รอบ | Analyst ขั้นต่ำ | Skeptic veto | พักหลังเทรด | จุดเด่น |
|------|-----|-----------------|--------------|-------------|---------|
| **Normal** (ค่าเริ่มต้น) | 120 วิ | 0.60 | 3 ข้อ | 30 นาที | ใช้งานจริง · สมดุล |
| **Aggressive** | 60 วิ | 0.52 | 4 ข้อ | 15 นาที | เร็วขึ้น ผ่อนเล็กน้อย |
| **Night** | 60 วิ | 0.55 | 3 ข้อ | 15 นาที | สแกนต่อเนื่อง · วอลุ่มขั้นต่ำสูง ไม่ไล่มีม |

ค่าเริ่มต้น = **Normal** · Night ถูกทำให้เข้มขึ้น deliberately (min volume $3M) เพื่อไม่ไล่เหรียญบาง
ทุกโหมดยังเป็น **paper trading เท่านั้น** · มี stop-loss / trailing / เพดาน drawdown เหมือนเดิม

News bot อ่านพาดหัว+สรุปข่าว 24 ชม. และให้โทน −1..+1 (ตัวเลือก: ตั้ง `ANTHROPIC_API_KEY` (และ `NEWS_MODEL`) ใน Render เพื่อให้ Claude วิเคราะห์ มีค่า API ตามการใช้งาน ไม่ตั้งก็ใช้คีย์เวิร์ด) · โทน ≤ −0.3 นับเป็นข้อค้านของ Skeptic

News bot ติดป้ายหัวข้อข่าว (EARN/LEGAL/REG/CRYPTO ฯลฯ) และเก็บโทนข่าวย้อนหลัง 24 ชม. แสดงเป็นกราฟในแผง "โทนข่าว" · บอกในแชทเมื่อโทนดีขึ้น/แย่ลงเทียบกับเดิม

SEC 8-K: ตั้งตัวแปร `SEC_CONTACT` ใน Render เป็นชื่อแอป+อีเมลจริงของคุณ (SEC บังคับให้ระบุตัวตนใน User-Agent) บอทจะดึง 8-K ของหุ้นที่ตรวจ ย้อนหลัง 3 วัน แสดงรหัสรายการ (เช่น 2.02 ผลประกอบการ, 5.02 ผู้บริหารเปลี่ยน) · รายการร้ายแรง (1.03, 3.01, 4.02, 1.05) บล็อกการเข้า · รายการต้องระวัง (2.04, 2.05, 2.06, 4.01, 5.02) นับเป็นข้อค้านของ Skeptic · ETF/คริปโตไม่มี 8-K ระบบจะข้าม

Time Machine: ทุกตัวที่ผ่านด่าน บอทจะย้อนรันกฎเทคนิคเดิม (EMA9/21 + RSI เข้า, แนวโน้ม/RSI ออก, stop −8%, trailing) กับแท่ง 5 นาทีย้อนหลัง ~30 วัน หักค่าธรรมเนียมทั้งสองฝั่ง แล้วรายงานจำนวนไม้ / ชนะ % / เฉลี่ยต่อไม้ / เทียบถือเฉยๆ · ถ้ามี ≥ 8 ไม้ และเฉลี่ย ≤ 0 หรือชนะ < 40% จะนับเป็นข้อค้านของ Skeptic · ไม่ได้ย้อนข่าว/วอลุ่ม/8-K (ไม่มีข้อมูลย้อนหลังฟรี) และ stop ตรวจที่ราคาปิดแท่ง จึงอาจดีกว่าจริงเล็กน้อย · ผลย้อนหลังไม่รับประกันอนาคต

Skeptic Scoreboard: ทุกครั้งที่ Skeptic บล็อกหรือปล่อยผ่าน ระบบจดราคาไว้ แล้วดูว่าราคาเปลี่ยนเท่าไรหลัง 4 และ 24 ชม. เทียบกลุ่ม "บล็อก" กับ "ผ่าน" เพื่อดูว่า Skeptic ช่วยจริงไหม (ต้องมี ≥ 20 ตัวอย่างต่อฝั่งถึงจะสรุป) · ราคาดิบ ไม่หักค่าธรรมเนียม · ข้อมูลหายเมื่อ redeploy บน Render free

# (ของเดิม) Phase 4 – 6 Agents

ระบบทดลอง Paper Trading สำหรับมือถือ เงินจำลองเริ่มต้น $10,000 (เปลี่ยนได้ด้วยตัวแปร `START_CASH` เช่น `50` แล้วกดรีเซ็ตบัญชี)
**ไม่มีการเชื่อมต่อบัญชีเงินจริง และไม่เชื่อมกับ MT5/XM**

## ทีม Agent (ส่งต่อแบบเข้มงวด ตัวไหนไม่ผ่านถูกตัดทิ้งและบันทึกเหตุผล)
1. **Scout** – หา BTC/ETH/SOL + เหรียญ alt ที่วอลุ่มสูงสุด 12 อันดับ (Binance) + หุ้นสหรัฐ 15 ตัว/ETF
2. **Filter** – 6 กฎตัดทิ้ง: spread กว้าง · งบประกาศภายใน 48 ชม. · funding (ใช้กับ perp เท่านั้น ระบบนี้เทรด spot จึงข้าม) ·
   วอลุ่มต่ำกว่าเฉลี่ย 30 วัน · ข่าวเสี่ยง (จับคำสำคัญในพาดหัว) · order book บาง
3. **Analyst** – ให้คะแนน 0–1 ต่ำกว่า 0.6 ถูกตัด (เป็นคะแนนจัดอันดับตามกฎ ไม่ใช่ความน่าจะเป็นที่จะกำไร)
4. **Risk** – ตั้ง stop −8% ก่อนเข้าเสมอ · trailing stop 8% เมื่อกำไรถึง +15% · รวมต่อตัวไม่เกิน 20% · หยุดเปิดสถานะใหม่ถ้าขาดทุนสะสม 20%
5. **Executor** – ส่งคำสั่งจำลอง ไม้ละไม่เกิน 5% ของพอร์ต ถือพร้อมกันสูงสุด 5 สถานะ (ทำงานเมื่อเปิดสวิตช์ Auto เท่านั้น)
6. **Logger** – บันทึกทุกการตัดออกและทุกคำสั่ง (ดูที่ช่อง Bot Activity)

รอบละ 120 วินาที · Risk เช็ก stop ทุก 5 วินาทีบนราคา live

## ข้อจำกัดที่ต้องรู้
- **ไม่มีระบบไหนรู้ล่วงหน้าว่าตัวไหนจะกำไร** Filter/Analyst แค่ตัดตัวที่ความเสี่ยงสูงและจัดอันดับตามกฎ ยังไม่เคย backtest
- ตัวที่ดึงข้อมูลบางกฎไม่ได้จะแสดงเป็น ❔ (ไม่ได้ตรวจ) ไม่ใช่ผ่าน/ไม่ผ่าน เช่น spread/order book ของหุ้น (ไม่มีข้อมูลฟรี)
- ข่าวใช้การจับคำสำคัญ ไม่ได้เข้าใจเนื้อหา · ไม่มี perps/futures
- หุ้นสหรัฐเทรดเฉพาะตอนราคา live (ตลาดเปิด ~21:30–04:00 น. เวลาไทยช่วงเวลามาตรฐาน)
- Render free: เซิร์ฟเวอร์หลับเมื่อไม่มีผู้ใช้ (ทีม Agent และ stop หยุดทำงาน) และไฟล์ SQLite หายเมื่อ redeploy
- ห้ามนำไปต่อเงินจริงโดยไม่ทำ backtest, security review และ risk validation

## รัน/Deploy
- ในเครื่อง: `pip install -r requirements.txt` แล้ว `uvicorn app:app --host 0.0.0.0 --port 8000`
- Render: Start Command `uvicorn app:app --host 0.0.0.0 --port $PORT --workers 1` · ตั้ง `APP_KEY` (รหัสเข้าใช้งาน) และ `PYTHON_VERSION=3.11.9`
- ตัวแปรเสริม: `START_CASH` (เงินเริ่มต้น), `DB_PATH` (ที่เก็บฐานข้อมูล)
- เทสต์: `pip install -r requirements-dev.txt && pytest` (ไม่มีในชุดสำหรับมือถือ)
